# 制作交接与验收

## 交接边界

只有用户要求分镜、图片、视频或剪辑时才进入对应制作阶段。写剧本不自动授权调用付费视频服务、向外部平台上传参考小说或发布成片。依当前授权继续必要工作，不把普通本地创作变成反复审批。

如果当前环境可用 `create-storyboard`，在用户要求分镜或生产素材时读取它的实际 `SKILL.md`，告知使用，再按其当前要求执行。此技能不内置其易变的模型限制、时长上限和完整目录规范，也不假定写了交接就已生成媒体。

若分镜技能不可用，仍可完成剧本、场景清单、角色/道具状态与交接文档；明确哪些生成或渲染未执行。无需为了纯剧本自动安装工具。

## 交接内容

`production_handoff.md` 应含：

- 制作范围：哪些已完成剧集、目标时长、真人/动画/AI、画幅等已确定项；未确定项明确标记。
- 当前剧本版本及可访问路径。已写剧本与季纲计划分开，不混作定稿。
- 全局角色、地点、道具 ID 表；服装、年龄与外观已确定信息，以及剧情必须保持的特征。
- 每集的场景顺序、季节/日夜、动作、情绪起止及集尾到下一集的连接。
- 重要道具与生产状态：粮袋空满、钱串数量量级、菜苗生长阶段、房屋修缮前后等。
- 大场面或难动作的原始叙事目的与可选简化拍法。
- 原创声明与参考使用方式；若为用户提供的原著改编，记录用户说明的来源与范围，不捏造授权。
- 图片、视频和配音的实际状态：未生成、已有可验证文件、生成受阻等。预计路径不能算实物资产。

交给分镜流程的是可表演场景及连续性信息，而非直接把整章小说塞进视频提示词。画幅或时长缺失时遵循正在使用的制作技能的要求；本技能的工作假设不能冒充用户确认。

## 当前范围的验收

### 参考学习

- 评价能追溯到实际读过的章节/范围；工具被截断的文字没有被算作完整阅读。
- 好读与适合短剧分别判断；不冒充全书排名或平台数据。
- 提炼的方法能够落实为原创决策，而非拼接原作情节。

### 故事与分集

- 主角有具体目标、主动决定和需要承担的后果。
- 钱粮、农时、地权/使用权、劳力和订单在关键处自洽。
- 配角有独立需要，关系变化有行动依据。
- 阶段性回报对应之前的期待；悬念不反复拖延而毫无进展。
- 关键事件得到充分展开，重复劳动和无效争吵没有充数。

### 剧本与制作

- 所有承诺为“完整”的集都有具体场景、动作、对白及结尾。
- 场景时长加总合理，台词与动作量可在估计时间内表演；若仅估算，明确标注。
- 场景/角色/道具 ID 一致；人物知情范围和物资变化没有越过尚未发生的事件。
- 大纲计划与已发生事实分开，下一集确实承接上一集。
- 已交付范围、剩余范围、剧本与媒体状态准确，文件路径可访问。

发现问题先修正文，再更新连续性记录和交接。不要仅附一段“建议优化”就把明显超时或缺场的剧本称为定稿。
