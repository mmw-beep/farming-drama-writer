# 长篇故事开发

## 先建立可持续的故事承诺

用具体的一句话确定：谁，在什么期限之前，必须解决什么问题，有何能力与限制，失败会失去什么。观众应知道为什么现在要看她做这件事。

没有选题时，提出少量真正不同的候选，例如农家合伙经营、年代返乡创业、灾后安居。比较人物矛盾、经营过程、影像表现和制作负担后推荐一个；用户已经选题时直接深化，不用重新投票。

小说正文和短剧不是前后必经的两道工序。用户要短剧时，可直接从故事设定和事件纲进入剧本；不强制先写一部长篇小说。用户要小说时，保留内心与叙述空间，但发展足够的具体事件。

## 人物与经营一起设计

主角记录：想得到的生活、眼前必须办成的事、专长来源、盲区、不愿承认的欲望、底线，以及哪些事会让她改变想法。

常驻配角记录：独立目标、可投入资源、缺少的能力、对主角的真实不满、合作底线、变化节点。母亲不只负责心疼，孩子不只负责嘴馋，伴侣不只负责体力，邻居不只负责夸奖。

关系弧应有可见证据：某人第一次不同意她、她第一次听进别人的判断、双方第一次共同承担损失。这些比反复表白或夸聪明更能支撑连续剧。

建立简明经营链：

`投入 → 生产/加工 → 品质与损耗 → 储运 → 顾客需求 → 定价与交易 → 回款 → 分配/再投入`

每个主要阶段选真正会卡住人物的环节，不要每次都让同行陷害。土地归属、借用期限、季节、劳力、现钱与账期都是可用约束。架空货币须相对自洽；真实年代关键制度和作物适应性应核实。

## 阶段推进

可按项目采用“安顿—试做—首单—稳定生产—合作扩张—重要取舍”的发展，但不要固定成所有故事的模板。阶段结束既解决当前承诺，也产生新的责任，例如拿到订单后必须按时供货，而不是突然换来无关的大反派。

关键事件卡：

- 起因与主角此刻的目标。
- 各方想法、掌握的信息和投入。
- 主角的办法，执行中产生的变化。
- 不能两全的选择及真实代价。
- 收入、损耗、信任、责任等具体后果。
- 哪个后果推动下一事件，哪个旧线索得到回收。

平静段落也可独立成戏：分一块布、决定送礼、修一张桌子。只要选择改变关系或兑现期待，就不必人为加吵架。

## 长度与节奏

先按用户篇幅确定事件容量，再分章节或集数。不要把“长篇”理解为把每场景写得冗长，也不要为了集数重复同一次误会。

以一个农年展开时，使用时间跳跃承认生长周期。跳过重复浇水，保留第一次失败、关键抢救、交易和家庭选择。上一场播种，下一场收获时必须让观众知道时间过去了；不能让一夜成熟除非已有明确奇幻规则。

若用空间、重生或技术知识，先确定能力边界和代价。新能力不能临时出现来解决已经写死的危机。没有金手指时，也不把主角写成无所不知的专家。

## 状态记录

`continuity.md` 区分“已经发生”和“大纲计划”，至少跟踪当前日期/季节、主要人物关系与知情范围、重要钱粮/债务/订单、农事进度、工具与道具、承诺及待回收线索。金额只记录会影响剧情的项，不必给每碗水记账。

每次续写核对上一章/集的结尾，兑现或推进它。未回收的悬念可以跨多集，但要有过程，不得无声丢弃。
